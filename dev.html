    Where to paste it:

    1. Open index.html in a text editor (Notepad, TextEdit, VS Code…).
    2. Near the top, find the line that starts with // >>> ANNOUNCEMENTS START.
    3. Select from that line down to the line that starts with // <<< ANNOUNCEMENTS END, both lines included.
    4. Paste. The old list is replaced by the new one. Save.
    5. Re-upload index.html to UsForge.

    Shortcut: if you opened your index.html in step 1, press Download updated index.html and upload that file. No pasting needed.
